# Blockfront Arena

[공개 게임 열기](https://englishmath75.github.io/blockfront-arena/)

VALORANT를 바탕으로 만든 비공식 팬 게임입니다. VALORANT는 Riot Games의 상표입니다.

한국어 요원과 무기를 사용하는 브라우저 FPS입니다. 플레이어가 방을 만들고 코드를 공유하거나 대기열에서 같은 맵과 모드를 선택한 사람끼리 만날 수 있습니다. 사격장은 혼자 입장하는 고정 표적 훈련장입니다.

## 실행

저장소 폴더에서 `npm ci`와 `npm run dev`를 차례로 실행하면 http://127.0.0.1:5174 에서 열립니다. 사격장 바로가기는 http://127.0.0.1:5174/?mode=range 입니다. 운영 서버는 `npm run build` 후 `npm start`로 실행합니다. `PORT` 환경 변수로 포트를 지정할 수 있습니다.

같은 Wi-Fi나 유선 네트워크에서 함께 플레이하려면 상위 폴더에서 `npm --prefix blockfront run lan`을 실행합니다. 참가자 모두 터미널에 표시되는 동일한 Network 주소를 열고, 한 사람이 만든 방 코드를 다른 사람이 입력합니다. 방과 대기열은 동일한 서버 프로세스를 사용합니다. 진행 중에는 방장이 브라우저를 열어 두어야 합니다. 정적 파일로만 호스팅할 경우 사격장을 이용할 수 있습니다. 플레이어 대전에는 포함된 방 서버가 필요합니다.

코드로 만든 경쟁전은 양 팀을 합쳐 2~10명이 입장해 시작할 수 있습니다. 공개 경쟁전 대기열은 10명이 연결되면 5대5로 시작합니다.

사용자 설정 게임에서는 방장이 경기 중 설정에서 치트를 켤 수 있습니다. 시계 정지, 단계·라운드 건너뛰기, 경기 재시작, 탄약·크레드·스킬 제한 해제를 지원합니다. 각 참가자는 유령 모드를 켜고 Space로 상승하거나 Ctrl로 하강할 수 있습니다.

## 조작

- WASD 이동, Shift 무음 걷기, Ctrl 무음 앉기, Space 점프
- 좌클릭 사격, 우클릭 조준 또는 보조 사격, R 재장전
- B 무기 구매, 1 주무기, 2 보조 무기, 3 근접 무기
- C/Q/E/X 스킬. 현재 스킬의 좌·우클릭, 누르기·놓기, 재사용 방법이 조준점 아래에 표시됩니다. 1/2/3으로 장착을 취소합니다.
- F로 문·로프·설치 장치 작동, Y로 무기 살펴보기
- 4 또는 F 유지로 설치·해체, F 습득, G 스파이크 내려놓기
- Tab 전광판, Esc 게임 메뉴. 잠금 없이 플레이할 때는 우클릭 드래그 또는 방향키로 조준
- 사격장에서 F2로 난이도를 고르고 F3으로 30표적 시험 시작

## 맵 자유 연습

로비에서 맵을 고르고 **맵 자유 연습**을 누르면 혼자 전장에 입장합니다. 무기와 스킬을 자유롭게 바꿀 수 있습니다. 로프 옆에서 F로 붙은 뒤 W/S로 이동합니다. 프랙처의 두 횡단 집라인은 한 방향으로 자동 이동합니다. 로터스 회전문은 스위치로 작동하고, 바인드의 순간이동기는 입구로 걸어 들어가 사용합니다. 서밋의 낙하벽은 스위치를 사격해 작동합니다.

어센트 A 서까래와 아이스박스 B 튜브에서는 같은 수평 위치에 위층과 아래층이 있습니다. 발판, 천장, 벽, 엄폐물에 대한 이동과 탄도 판정에 전장 삼각형 충돌 메시을 사용합니다. 전장 파일은 선택한 맵 단위로 읽습니다.

## 구현 범위

총기 데이터에는 가격, 탄창, 발사 속도, 초탄 오차, 재장전 시간, 산탄 수, 부위와 거리에 따른 피해가 들어 있습니다. 스킨 장착 상태는 브라우저에 무기별로 저장됩니다. 프라임 밴달·클래식·스펙터·가디언, 약탈자·엘더플레임·아이온·혼돈의 서막 밴달은 Riot 시연 영상에서 잘라낸 사격음과 재장전음을 사용합니다. 컬렉션에서 요원과 스킨 단계를 고른 뒤 외형 회전, 장착, 재장전, 살펴보기를 실행할 수 있습니다. 게임과 미리보기는 같은 3D 손과 무기를 사용합니다.

1,396개 스킨의 손과 총을 3D로 렌더링합니다. 전용 모델이 있는 스킨은 고유한 표면과 뼈대를 사용합니다. 그 밖의 스킨은 컬렉션 외형과 해당 무기의 뼈대를 바탕으로 입체화합니다. 로그·싱귤래러티·2023 챔피언스·아락시스·넵튠 밴달에는 별도로 모델링한 부품을 적용했습니다. 스킨별로 확인한 공격음과 장전음을 연결하고 전용 음원이 부족한 경우 해당 무기의 기본음을 사용합니다. 워든의 기본 사격·장전음은 자체 제작했습니다. [VALOTOWN 효과음 자료](https://valo.town/weapons/) · [Riot 무기 스킨 제작 설명](https://playvalorant.com/en-us/news/dev/the-craft-and-fantasy-of-valorant-weapon-skins/)

요원은 스킬별로 입력과 조준 방식을 사용합니다. 소바는 활시위를 당겨 사거리와 속도를 조절하고 우클릭으로 반사 횟수를 지정합니다. 브림스톤은 전술 지도에 연막 위치를 표시한 후 우클릭으로 전개합니다. 세이지는 장벽을 회전하고, 회복 구슬의 마우스 버튼으로 치유 대상을 고릅니다. 드론 조종, 설치 장치 재사용, 독성 연료와 연막 거리 조절도 구현했습니다. 제트 연막은 투사체의 방향을 유도할 수 있고 네온 추월 차선은 지형을 따라 양쪽 벽이 펼쳐집니다. 소바 정찰 화살의 두 차례 감지와 테호 드론의 탐지는 엄폐물을 확인합니다. 오멘의 연막은 속이 빈 구형이며 E로 투사 위치를 확정합니다. 116개 스킬의 시간 자료가 포함되어 있습니다. 각 스킬의 애니메이션과 판정에는 재구성한 부분이 있습니다.

13개 전장은 공개 3D 장면의 삼각형과 텍스처를 사용합니다. 이동과 탄도 계산에는 별도의 3차원 충돌 메시를 사용합니다. A·B·C 설치 구역의 수평 경계는 공식 미니맵에서 추출했습니다. 높이 허용 범위, 일부 기믹의 작동 범위와 전장 조명에는 근사값이 들어갑니다. 사용자 설정 게임, 경쟁전, 신속플레이, 데스매치, 스파이크 돌격을 선택할 수 있습니다. [SpikeAtlas 전장 자료](https://spikeatlas.com/en-us/) · [Riot 맵 소개](https://playvalorant.com/ko-kr/maps/)

게임 명칭과 아이콘, 스킨 이미지, 무기 수치, 맵 평면도는 [Valorant-API](https://valorant-api.com/) 공개 게임 데이터에서 가져왔습니다. 요원·무기 모델과 애니메이션은 [Kingdom Archives 모델 뷰어](https://kingdomarchives.com/modelviewer/jett-fp?held=prime-vandal)의 공개 자료에서 변환했습니다. 능력의 구매 가격, 충전 상한과 궁극기 포인트는 [VALORANT Wiki](https://wiki.playvalorant.com/en-us/Abilities)의 표를 참조했습니다.

`npm --prefix blockfront test`로 규칙을 검증하고 `npm --prefix blockfront run build`로 빌드합니다.

## 플레이 자료

소바의 정찰 펄스는 녹화의 5.77~6.84초 구간에서 분리했습니다. 세이지의 둔화 구슬은 헤이븐 시연에서 장판이 퍼지는 127.81초 구간과 요원이 얼음 위를 움직이는 118.95~120.79초 구간을 사용합니다. 발걸음 세 개를 번갈아 재생하고 듣는 사람의 거리·방향과 음량 설정을 적용합니다. [소바 정찰음 녹화](https://www.youtube.com/watch?v=RAxyC9GYhv0) · [세이지 능력 시연](https://www.youtube.com/watch?v=VGLUoWNvDbc)

장전과 살펴보기는 장착한 요원의 손과 무기 뼈대를 움직입니다. 일부 스킨에는 시연에서 측정한 궤적과 손가락 방향을 더했습니다. 전용 동작 자료가 부족한 스킨에는 무기 메시의 접촉점으로 손가락 자세를 보정합니다. 이 자세는 원작 손동작의 실측값과 차이가 있습니다. 소바의 세 활 스킬은 실제 입력에 맞춰 현과 화살, 양팔이 함께 움직입니다.
